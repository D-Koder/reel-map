USE CASE 1: SAVE A REEL FROM PARTNER
===============================================

ACTOR: Sarah (user)
TRIGGER: Partner Alex sends Instagram Reel link in text: "Let's go here! 🍷"

MAIN FLOW:
  1. Sarah opens Reel Map app
  2. Taps "+" button (not yet in MVP, use manual for now)
  3. Pastes link: https://instagram.com/reel/ABC123def456/
  4. Regex extracts: "Wine & Wild" at Melbourne
  5. Google Maps lookup: confirms address, hours, type
  6. Sarah confirms location is correct
  7. Sarah selects collection: "Date Night"
  8. Reel saved to collection
  9. Toast: "✓ Added to Date Night"
  10. Sarah continues browsing other reels

ALTERNATE FLOW (No Instagram link):
  1. Sarah taps manual search
  2. Autocomplete: "Wine & Wild Carlton"
  3. Sarah selects from dropdown
  4. Saves to collection as above

POSTCONDITION:
  • Reel appears in "Date Night" collection
  • Alex can see it (if collection is shared)
  • Ready for step 2: rating

===============================================
ERROR SCENARIOS
===============================================

ERROR 1: Invalid Instagram Link
  Input:  "https://instagram.com/user/"
  Result: Toast: "❌ Not a valid Reel link"
  Action: User can retry or search manually

ERROR 2: Restaurant Closed / Deleted
  Input:  Reel about restaurant that closed
  Result: Google Places returns: "No longer available"
  Action: Modal shows warning, user can update/delete

ERROR 3: Booking Unavailable
  Input:  Try to book on Monday (closed day)
  Result: Modal warning: "This location is closed Monday"
  Action: User selects different day

ERROR 4: Partner Rejects Invite
  Input:  Alex clicks "Decline" on email invite
  Result: Collection not shared with Alex
  Action: Sarah can resend or share code instead

ERROR 5: Offline (PWA future)
  Input:  User loses internet connection
  Result: App loads from cache
  Action: Can view saved reels, changes sync when online
