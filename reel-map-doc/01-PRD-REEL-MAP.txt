===============================================
1. EXECUTIVE SUMMARY
===============================================

Reel Map is a social location-saver app for couples/friend groups. 
Users save Instagram Reels → rate them together → plan dates → book → capture memories.

PROBLEM: Partners send Reel links all week. Users forget them, never action them.
SOLUTION: Save → Rate → Plan → Book → Done


===============================================
2. TARGET AUDIENCE
===============================================

PRIMARY:
  • Couples aged 25-35
  • Friend groups (2-4 people)
  • Active Instagram users
  • Date planners who like curation

SECONDARY:
  • Solo users organizing personal bucketlists


===============================================
3. CORE FEATURES
===============================================

ENTRY POINT:
  • Paste Instagram Reel link (regex extracts location)
  • Manual search (Google Places autocomplete)
  • Instagram Graph API (Week 3+, pending Meta approval)

COLLECTIONS / BOARDS:
  • User creates custom collections: "Date Night", "Brunch Spots", "Weekend Vibes"
  • Collections show items with gradient backgrounds:
    - 🔥🔥 Both in = warm orange/coral gradient
    - 🔥😐 Mixed vibes = muted gold/amber gradient
    - 😐😐 No consensus = soft gray/neutral gradient

RATING SYSTEM:
  • Both users rate independently: 😐 / 🤔 / 🔥
  • Auto-routing: Both 🔥 → Do Soon; Mixed → Explore Together

ACTIVE BOOKINGS:
  • Green 🟢 pulsing dot on items with confirmed reservations
  • Modal shows planned date/time
  • Booking step skipped in checklist if already booked
  • "Mark as Done" button only clickable 1 hour after booking time

PROGRESSIVE PLANNING CHECKLIST:
  1. Check hours (confirm open, yes/not now)
  2. Book reservation (OpenTable/Call/Skip)
  3. Add to calendar (date + custom title)
  • Step only marks done AFTER user completes action
  • Final screen: "All set!" → Mark as Done

MAP VIEW:
  • Color-coded pins (orange=do-soon, gold=explore, green=completed)
  • Filters: All / Cafe / Food / Event
  • Tap pin → shows modal

SHARING / AUTH (MVP):
  • Magic link invite (email specific)
  • Shareable code with expiry options (future)
  • Collections can be marked private/shared

SMART NUDGE:
  • Friday evening notification for "Do Soon" items
  • Capped 1/week max

POST-ADVENTURE CAPTURE:
  • Rating (required), note (optional), tags (optional)
  • Mark as Done → streak +1

7. API ENDPOINTS (MVP)
===============================================

AUTH:
  POST   /api/auth/magic-link         (send invite)
  POST   /api/auth/verify             (verify token)
  POST   /api/auth/logout
  GET    /api/auth/me

REELS:
  POST   /api/reels                   (create)
  GET    /api/reels                   (list all)
  GET    /api/reels/:id               (single)
  PUT    /api/reels/:id               (update)
  DELETE /api/reels/:id               (delete)

COLLECTIONS:
  POST   /api/collections             (create)
  GET    /api/collections             (list user's)
  GET    /api/collections/:id         (single)
  PUT    /api/collections/:id         (update name/privacy)
  DELETE /api/collections/:id
  POST   /api/collections/:id/items   (add reel to collection)
  DELETE /api/collections/:id/items/:reel_id (remove)

BOOKINGS:
  POST   /api/bookings                (save reservation)
  GET    /api/bookings/:id            (check status)
  PUT    /api/bookings/:id            (update date/time)
  DELETE /api/bookings/:id            (cancel)

SHARING:
  POST   /api/share/generate-code     (create shareable code)
  POST   /api/share/invite-email      (send magic link)
  POST   /api/share/accept/:code      (join collection)

LOCATION SERVICES:
  POST   /api/extract-location        (regex Instagram URL)
  GET    /api/places/search           (Google Places autocomplete)
  GET    /api/places/:id/details      (hours, phone, rating)


===============================================
8. USER FLOWS
===============================================

FLOW 1: SAVE A REEL
  User receives Reel from partner
  → Paste link in app
  → Regex extracts location
  → User confirms location
  → Add to collection
  → DONE

FLOW 2: RATE TOGETHER
  Partner opens shared collection
  → See pending reels
  → Both rate independently
  → App auto-routes by consensus
  → DONE

FLOW 3: PLAN A DATE
  User clicks "Book now"
  → Step 1: Confirm hours work
  → Step 2: Choose date/time, book reservation
  → Step 3: Add to calendar
  → Mark as Done (1 hour after booking time)
  → DONE

FLOW 4: CAPTURE MEMORY
  Day after visit
  → User clicks pin
  → Rate experience
  → Add note/photos
  → Mark as Done
  → Streak +1
  → DONE
