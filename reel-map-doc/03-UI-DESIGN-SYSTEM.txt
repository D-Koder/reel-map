ANIMATIONS
===============================================

slideUp:
  from: { transform: translateY(100%), opacity: 0 }
  to:   { transform: translateY(0), opacity: 1 }
  duration: 0.3s ease-out

slideInUp:
  from: { transform: translateX(-50%) translateY(100%), opacity: 0 }
  to:   { transform: translateX(-50%) translateY(0), opacity: 1 }
  duration: 0.3s ease

pulse:
  0%, 100%: { opacity: 1 }
  50%:      { opacity: 0.6 }
  duration: 2s infinite


ACCESSIBILITY
===============================================

• Min tap target: 44px × 44px
• Color contrast: WCAG AA minimum
• Focus states: visible border or outline
• Alt text: on all icons/images
• ARIA labels: on interactive elements
• Keyboard nav: Tab through all buttons
• Screen reader: semantic HTML (button, nav, etc.)


DARK MODE (Future)
===============================================

Currently: Light mode only

When adding dark mode, toggle via CSS variables:
  --bg-primary: #fefdfb (light) → #1a1a1a (dark)
  --text-primary: #2c2c2a (light) → #f5f5f0 (dark)
  --border: #d3d1c7 (light) → #333333 (dark)
  --gradient-both-in: ... (adjust opacity/colors)


MOBILE CONSIDERATIONS
===============================================

• Portrait orientation primary
• Safe area insets: padding-top/bottom env()
• Scrollable sections: avoid full-height
• Buttons: tap-friendly spacing (8px min gap)
• Input fields: 44px min height
• No hover states on touch devices
• Swipe gestures: future consideration
